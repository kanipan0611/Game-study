# ⚔ FP QUEST — 資格取得の冒険へ。

FP3級（基礎編）からFP2級（応用編）合格までを目指す学習RPG。
ドラクエ風の冒険（6つのダンジョン・ボス戦・育成）と、Duolingo風の継続学習（ストリーク・デイリー/ウィークリー・間隔反復）を組み合わせています。

```bash
npm install
npm run dev      # 開発サーバー
npm test         # データ整合性・計算エンジン・XPルールのテスト
npm run build    # dist/ に静的ファイルを出力（どこでも配信可・相対パス）
```

## データ構造（`src/types.ts`）

- **Question**：`field`（6分野）/`grade`（3・2）/`stage`/`format`（○×・択一・複数選択・計算・事例）/`topic`（スキルツリー）/選択肢ごとの`why`/`steps`（途中過程）/`bridge`（3級⇔2級の関連）/**`law`（法令基準日・根拠・出典・検証状態）**
- **QuestionRecord**：解答数・正解数・SRSの箱・次回期限・XP付与履歴（稼ぎ防止）
- **BookEntry**：市販教材の学習記録。問題文・解説は保存しない。`origin: 'manual' | 'csv' | 'ocr'` で将来のOCR取込に対応
- **GameState**：上記＋日別ログ、クエスト、実績、模試履歴。LocalStorage（`fpquest.save.v1`）に保存

問題データ（`src/data/questions/*.ts`）とプログラムは分離。CSVで追加した問題も同じ `Question` 型に変換されます。

### CSV形式
- 学習記録：`book,chapter,page,problemNo,field,grade,status,understanding,weak,linkedStage,memo,correctCount,wrongCount`
- 問題：`id,field,grade,format,topic,prompt,choiceA..D,whyA..D,answer,unit,explanation,steps(|区切り),basisDate,basis,source`
- `field` は `life` / `ライフ` / `タックスプランニング` などの表記を受け付けます。テンプレートはアプリ内からダウンロード可能。

## 「ゲームLv ≠ 実力」を防ぐ設計

- XPは**初回正解**と、**復習期限が来た問題で定着Lvが上がった時**だけ。同じ問題の連打・期限前の再挑戦・閲覧は0XP
- ステージ制覇・ボス撃破・相談解決は初回のみ。計算特訓・教材記録は1日上限あり
- 評価には正答数だけでなく、**苦手克服ボーナス**、**2級問題の倍率**、**復習完了**、模試の結果を反映
- ホームの「実力メーター」は XP を使わず、定着度60％＋直近の学科模試40％で算出。Lvが高く定着が低いと警告
- ○×問題の正誤比率をテストで監視（当て推量で勝てないように）

## 法改正・正確性の方針

- 全問題に `law.basisDate`（現在 **2026-04-01**：2026年6月〜2027年5月受検分）・根拠法令・出典・検証状態を付与
- 状態は `verified` / `needs-review` / `outdated`。CSVで取り込んだ問題は必ず `needs-review`（「現行制度確認済」と表示しない）
- 改正が多い論点（住宅ローン控除、基礎控除など）は数値問題にせず、扱う場合は「要確認」と注記
- 公式過去問は収録せず、すべてオリジナル問題。市販問題集の問題文・解説は保存しない
- 試験制度（2026年度CBT）：3級学科 60問・90分・36/60点、3級実技（FP協会）20問・60分・60/100点、2級学科 四答択一60問・120分・36/60点、2級実技（FP協会）40問・90分・60/100点。出典：日本FP協会・金融財政事情研究会の試験概要。**受検前に公式サイトで最新情報を確認してください**
